# AutomationCapture

AutomationCapture is a Python project for discovering browser workflows with an LLM, recording reusable automation artifacts, and replaying workflows deterministically. The repository will include Selenium browser automation, a local Flask test application, safety controls, structured JSON logging, and pytest tests as the project phases are implemented.

This first phase establishes the dependency list, example environment configuration, and package structure. Application behavior will be added in later phases.
